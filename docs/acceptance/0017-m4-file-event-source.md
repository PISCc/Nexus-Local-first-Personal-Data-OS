# M4.1 文件事件来源验收记录

## 验收范围

本记录验收本地文件通知是否能够进入 Nexus 核心，并被转换为稳定、与索引业务解耦的事件。事件去重、防抖、批量解析、数据库更新和桌面后台任务属于 M4.2–M4.3。

## 用户可理解的结果

监听指定目录后，核心层能够报告：

- 新路径出现；
- 文件或目录发生变化；
- 路径消失；
- 文件或目录完成重命名/移动；
- 底层通知不完整，需要重新扫描整个监听目录。

监听范围外的路径不会进入事件流；监听本身不会读取用户正文或上传任何数据。

## 已执行验证

- `cargo test -p nexus-core`

结果：`nexus-core` 53 项测试全部通过，其中包含真实临时目录的文件监听测试。

## 当前限制

- 尚未把事件接到增量索引写入流程；监听到事件后不会自动更新搜索结果。
- 尚未合并短时间内重复事件，也没有稳定性等待和批处理重试。
- 分离的 From/To 只有在连续到达时配对；复杂事件顺序由 M4.2 处理。
- 底层事件丢失时只发出完整重扫信号，重扫调度留给 M4.3。

## 结论

M4.1 达到当前定义的验收范围，可以进入 M4.2 去重、防抖与批处理。
