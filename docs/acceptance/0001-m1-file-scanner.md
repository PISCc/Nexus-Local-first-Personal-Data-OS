# M1 验收记录：本地文件扫描

- 状态：已通过
- 日期：2026-09-01
- 范围：M1.0–M1.5

## 验收结论

M1 已完成当前约定范围：Nexus 可以从用户输入的完整目录路径开始一次本地手动重扫，读取文件元数据，按有界批次写入 SQLite，并在桌面界面中观察进度、取消任务和查看结果统计。

本次验收不引入原生目录选择器。完整路径输入已经满足当前最小交互；原生选择器需要额外的桌面插件依赖，留待真实使用反馈证明必要后再单独评估。

## 条目与证据

| 条目 | 结果 | 证据 |
| --- | --- | --- |
| 用户可以选择扫描目录 | 通过 | 文件索引界面提供完整路径输入和开始重扫操作 |
| 文件元数据写入本地数据库 | 通过 | `nexus-db` 重扫测试覆盖新增、更新、移除和 SQLite 持久化 |
| 权限失败、删除、修改、符号链接和忽略路径 | 通过 | `nexus-core` / `nexus-db` 测试覆盖；Unix 专属测试在 Unix CI 环境执行 |
| 单文件错误不会终止全局扫描 | 通过 | `FileScanner` 逐项产出 `Failed`，后续条目继续处理 |
| 100,000+ 文件规模 | 通过 | `nexus-db` 的 100,000 条合成元数据测试按 1,024 条一批完成 |
| UI 不被扫描阻塞 | 通过 | Tauri 使用后台线程；桌面开发构建实际启动成功 |
| 取消后数据库一致 | 通过 | 取消测试验证持久化数据库保持原状，pending 临时数据不会应用 |
| 重复启动行为明确 | 通过 | Tauri 活动任务槽位拒绝第二个任务并返回 `rescan_already_running` |

## 已知限制

- 当前目录选择是完整路径输入，不是原生目录选择对话框。
- 本地验收环境是 Windows；Unix 专属符号链接和非 UTF-8 路径测试已保留在条件编译中，交由 Unix CI 执行。
- M1 只建立文件元数据索引，不读取正文，不提供全文搜索，也不接入实时文件 watcher。
