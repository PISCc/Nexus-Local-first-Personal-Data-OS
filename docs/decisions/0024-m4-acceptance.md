# ADR 0024：M4 增量索引最终验收

## 状态

已接受（2026-09-02）

## 验收目标

确认 M4 从文件变化产生通知，到本地元数据、canonical 文档和全文索引最终保持一致，
并覆盖常见编辑器保存方式、重复事件、移动、删除、关闭和重新启动。

## 验收原则

- 以文件系统当前状态为事实，不把某一条通知当作最终结果。
- 同一个本地文件在 canonical 文档和 FTS 中最多保留一条有效记录。
- 临时文件不应因为编辑器中间步骤变成可见正文记录；完成原子保存后只处理最终路径。
- 单项解析失败、事件丢失或数据库批次失败都不能静默制造半条索引状态。
- 关闭后重新启动通过完整本地恢复弥补离线期间遗漏的通知，不依赖网络或 AI。

## 决策

M4 的最终验收采用核心层真实临时目录测试、数据库事务测试、桌面配置恢复测试和前端
事件边界测试组合完成。验收不把操作系统通知的具体时序作为稳定契约，而是直接验证
归并后的操作作用于当前文件状态后，查询结果和记录数量正确。

## 不在本次验收内

不验收多目录配置、系统托盘常驻、网络同步、语义检索、向量索引或 Agent 行为；这些都
属于 M4 之外的范围。
