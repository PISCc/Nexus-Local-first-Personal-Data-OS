# Bundled font licenses

The desktop application bundles the following open-source fonts so the
Organic Memory Field interface keeps its approved typography when running
offline:

- **DM Sans** — SIL Open Font License 1.1. Source:
  <https://github.com/google/fonts/tree/main/ofl/dmsans>
- **IBM Plex Mono** — SIL Open Font License 1.1. Source:
  <https://github.com/google/fonts/tree/main/ofl/ibmplexmono>
- **Poppins** — SIL Open Font License 1.1. Source:
  <https://github.com/google/fonts/tree/main/ofl/poppins>

The license text and copyright notices are maintained by the upstream font
projects at the linked sources. These files are used only as local static
assets; the application does not fetch fonts at runtime.
