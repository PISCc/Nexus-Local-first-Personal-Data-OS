# ADR 0010：M2.3a HTML 解析边界

- 状态：已接受
- 日期：2026-09-01
- 范围：`crates/nexus-core`

## 背景

M2.1 已建立单文件 UTF-8 文本解析，M2.2 已建立 JSON 合法性和资源边界。M2.3a
需要把本地 HTML 文件转换为可供后续搜索层使用的统一文本 `Document`，同时不把
HTML 的 DOM、脚本或页面展示逻辑泄漏到 UI、数据库或后续全文搜索之外。

## 决策

### 1. 使用工作区已有版本的 dom_query

`nexus-core` 增加直接依赖 `dom_query = "0.27.0"`。该版本已经通过桌面依赖存在于
`Cargo.lock`，因此不会引入第二个 HTML 解析版本。使用 HTML5 容错 DOM 解析和现成的
文本遍历能力，不手写 tokenizer，不为当前单一需求引入新的通用解析框架。

### 2. 保持单文件显式 API

公开入口为：

```text
parse_html_file(document_id, path, max_input_bytes, max_output_bytes)
    -> Result<Document, ParseError>
```

调用方提供文档 ID、本地路径、原始文件字节上限和提取后正文字节上限。解析器只处理
一个 `.html` 或 `.htm` 普通文件，不遍历目录、不批量调度、不写数据库。

### 3. 只输出确定性的可见文本

输入按严格 UTF-8 解码，只移除开头的 UTF-8 BOM。HTML5 容错解析后，移除 `script`、
`style`、`noscript` 和 `template` 元素及其后代；从 `body` 提取其余文本，并使用
确定性的空白归一化和块元素换行规则。`head` 中的标题、样式和元数据不作为正文；
没有标准 `body` 时才回退到解析文档的文本结果。

HTML 的页面样式、链接属性、脚本代码、注释和原始标签不进入 `Document.body`。本单元
不执行脚本、不请求网络、不解释资源 URL，也不尝试把 HTML 映射为 Markdown。

### 4. 沿用当前 Document 位置边界

标题使用完整文件名，来源使用规范化后的本地文件路径，位置使用
`DocumentLocation::whole_document()`。M2.3a 不增加 DOM 路径、元素偏移或行列字段，
避免为单一格式提前改变公共数据模型。

### 5. 明确错误和资源行为

输入和输出上限必须大于零；原始文件超过输入上限，沿用 `parse_file_too_large`；提取
文本超过输出上限，返回 `parse_output_too_large`。元数据、打开、读取、UTF-8 和
Document 构造错误沿用 M2.1/M2.2 分类。malformed HTML 由 HTML5 解析器容错恢复，不能
仅因为标签不完整就把整份文件判为失败；无法读取、无法解码或超出边界时仍安全返回。

展示错误不包含路径、文件名、正文或原始系统错误；单个文件解析失败不改变后续调用
能力，不上传任何数据，也不生成数据库或 UI 副作用。

## 备选方案

- 直接保存原始 HTML：会把标签、脚本和样式带入后续检索，降低文本质量，因此输出
  可见文本。
- 手写 HTML tokenizer：重复实现 HTML5 恢复规则，遇到真实网页容易产生不一致结果，
  因此使用已有 HTML5 DOM 解析库。
- 使用通用 HTML-to-Markdown 工具：会引入额外格式转换语义和依赖；M2.3a 只需要统一
  文本，因此不做 Markdown 转换。
- 为 DOM 节点增加位置字段：当前 Document 只有行范围，且本单元不需要按元素定位，
  因此保留 whole-document 结果，把位置扩展留给有真实需求的后续 ADR。

## 结果与取舍

- HTML 解析依赖一个已经存在于锁文件的直接声明；不新增 PDF、DOCX 或压缩包依赖。
- 可见文本提取会构造临时 DOM，峰值内存可能高于原始文件大小；输入和输出上限只
  约束当前可观测边界，后续仍需用真实语料测量。
- 仅支持 UTF-8；其他编码不会被静默替换，避免产生不可追溯正文。
- 输出丢失原始标签和 DOM 位置，但后续 `Document` 可直接用于确定性词法搜索；原始
  文件路径仍保留为来源。

## 验证

- 覆盖 `.html` / `.htm` 大小写扩展名、实体、块边界、BOM、malformed HTML、脚本/样式/
  noscript/template 过滤、无效 UTF-8、输入限制、输出限制和安全错误展示。
- 使用隔离临时目录测试；不读取真实用户目录，不执行脚本，不访问网络，不写 SQLite。
