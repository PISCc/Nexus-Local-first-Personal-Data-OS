# Nexus

Nexus 是一个本地优先的个人数据操作系统。它把文件、笔记和代码整理成可搜索、可追溯的
本地内容，让你在自己的设备上找回已经拥有的信息。

当前版本：`v0.1.0`

## 你可以用 Nexus 做什么

- 为指定文件夹建立本地索引。
- 搜索文本、Markdown、代码、JSON、HTML、DOCX 和 PDF 内容。
- 按关键词、短语、文件名、路径、扩展名和日期缩小搜索范围。
- 从搜索结果直接定位原始文件。
- 文件新增、修改、删除或移动后自动更新索引。
- 在本地使用全文检索，并在可用时加入本地相关性排序。

## 快速开始

### 运行环境

从源码运行 Nexus 需要：

- Windows 10 或更高版本。
- Node.js 22 或更高版本，以及 pnpm 11。
- Rust stable 工具链。
- Visual Studio C++ 构建工具、Windows SDK 和 WebView2。

### 安装

在 PowerShell 中执行：

```text
git clone https://github.com/PISCc/Nexus-Local-first-Personal-Data-OS.git
cd Nexus
pnpm install --frozen-lockfile
```

### 启动桌面应用

```text
pnpm dev
```

桌面应用提供完整的本地索引、搜索和自动同步能力。首次运行时，Nexus 会在应用数据目录
创建本地数据库。

### 打开演示页

如果只想查看界面和交互状态，可以运行：

```text
pnpm dev:web
```

然后打开 [http://127.0.0.1:1420](http://127.0.0.1:1420)。演示页不连接桌面核心，不能执行
真实的文件索引；页面显示“降级 / 需处理”属于正常现象。

## 第一次使用

1. 启动桌面应用后，打开左侧的“文件索引”。
2. 在“扫描目录”中输入要整理的文件夹完整路径，例如：
   `C:\Users\你的名字\Documents`。
3. 点击“开始索引”，等待任务完成。
4. 打开“全文搜索”，输入关键词并按 Enter 或点击“搜索”。
5. 点击搜索结果即可定位或打开原始文件。

建议先选择一个明确的工作文件夹进行体验，不要一开始就索引整个系统盘。索引完成后，文件
变化会在本地自动同步。

## 支持的文件

| 类别 | 格式 |
| --- | --- |
| 文本与代码 | `.txt`、`.md`、`.py`、`.rs`、`.js`、`.ts`、`.java`、`.cpp` |
| 结构化文本 | `.json` |
| 网页与文档 | `.html`、`.htm`、`.docx`、`.pdf` |

不支持的格式会被跳过。单个文件损坏、无法读取或内容不符合格式时，会记录为失败并继续
处理其他文件，不会因此中断整个索引任务。

## 搜索方法

在搜索框中输入关键词、短语或筛选条件：

| 写法 | 用途 | 示例 |
| --- | --- | --- |
| 关键词 | 搜索包含这些词的内容 | `季度 计划` |
| `"短语"` | 搜索连续出现的短语 | `"季度计划"` |
| `filename:` | 按文件名筛选 | `filename:"会议记录"` |
| `path:` | 按路径筛选 | `path:Documents` |
| `ext:` | 按扩展名筛选 | `ext:md` |
| `type:` | 按文件类型标记筛选 | `type:text/markdown` |
| `modified` | 按修改日期筛选 | `modified>=2026-01-01` |
| `created` | 按创建日期筛选 | `created=2026-01-01` |
| `accessed` | 按访问日期筛选 | `accessed<=2026-01-01` |

多个条件用空格连接。日期格式为 `YYYY-MM-DD`。搜索结果只显示必要的摘要和原文件引用，
不会把完整正文发送到网络服务。

## 隐私和数据归属

- 文件内容、文件名、路径、向量和搜索历史默认只保留在本机。
- Nexus 不要求云服务，也不要求登录或人工智能服务。
- 数据库保存在本地应用数据目录。
- 日志不会默认记录文件正文、搜索词或完整用户路径。
- 你可以随时删除本地数据库或索引目录；这不会删除原始文件。

## 当前限制

- 当前仓库主要通过源码运行，暂未提供正式安装包。
- 本地相关性排序使用确定性基线，不是预训练语言模型；它用于补充检索，不保证理解同义词或
  复杂语义。
- 大规模真实资料库仍需要持续进行性能和搜索质量验证。
- 当前不包含云端同步、多人协作、问答助手或 Agent 功能。

## 常见问题

### 为什么浏览器演示页显示“本地核心暂不可用”？

浏览器演示页只展示前端界面。要执行真实索引和搜索，请关闭演示页对应的预览方式，运行
`pnpm dev` 启动桌面应用。

### 搜索没有结果怎么办？

先确认已经完成一次索引，并检查输入的目录路径是否正确。然后尝试使用文件中的明确词语，
或去掉筛选条件；不支持的文件格式不会产生可搜索正文。

### 索引过程中取消会怎样？

已经完成并保存的部分会保留，尚未完成的部分会被丢弃。原始文件不会被修改或删除。

### 文件变化没有立即出现在结果中？

自动同步需要在首次索引成功后启用。请确认桌面应用仍在运行；必要时重新执行一次索引，
让 Nexus 重新确认目录状态。
